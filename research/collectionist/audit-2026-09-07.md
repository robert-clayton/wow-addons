# Collectionist audit — September 7, 2026

The 1.13.2 audit found nine actionable issues. Release 1.14.0 fixes the
confirmed runtime and catalog defects and restores source-backed coordinates.

| Finding | Resolution |
| --- | --- |
| Mount ownership and mount/toy search icons use wrong API slots | Corrected the `pcall` return lists; tested owned/hidden/unowned states and numeric icons. |
| Quest/spell achievement assets treated as gameobjects or NPCs | Retain criterion type, use separate NPC/object/quest fields, and link spell-backed criteria to the achievement. |
| Older rare and treasure coordinates absent | Added 2,207 ID-based lookup entries with 2,630 coordinate tuples, covering 1,934 older criteria. Localized names no longer determine these matches. See the [source record](sources/criterion-waypoints.md). |
| Raw search and new Targets omit supplemental pins | Share the waypoint resolver with scanners, including faction-specific recipe trainers. |
| Multi-spawn routing keeps only the first in-zone spawn | Keep all local spawns; tested the three J'imothy bushes and mixed-zone lists. |
| Long Silvermoon Table and Replica Dark Iron Mole Machine missing | Added both decor/item ID pairs with sources, costs and restrictions. The Mole Machine vendor is in the Dark Iron allied-race version of Blackrock Depths (map 1186), so its acquisition is filed under BFA. |
| Task and multi-spawn TomTom calls throw or claim false success | Route each marker through the guarded helper and count only accepted markers. |
| Database round trip drops 101 pet guides | Store and emit `steps`; reject failed inserts, dropped non-scalar fields and substantive integrity violations. Historical waypoints on unavailable entries remain tracked information. |
| 31 wrong or missing pet families | Corrected 23 wrong families and filled eight missing families using BattlePetSpecies.PetTypeEnum + 1. |

The waypoint work also corrected the Krasarang Wilds achievement's wrong
Isle of Thunder placement and prevented the ATT extractor from reading a
neighboring node's coordinates. Scanner location labels now follow a known
single-zone waypoint when the achievement covers a larger area.

The catalog round trip preserves all 18,747 dumped rows, 97 shared location
rows, 3,247 recipe lookup entries, 2,921 trainer entries and all new criterion
pins. Tests exercise API return positions, namespace collisions, localization,
criterion-count changes, multiple spawns and failing waypoint providers.
Release validation also runs TOC/XML load checks, existing scanner/UI tests,
strict database failure tests and package validation. These are offline tests;
no live WoW session was available.

The follow-up audit and release 1.15.0 resolve another 73 source-backed
criteria. Still unverified: 97 older criteria have no accepted coordinate in
these snapshots (23 rares, 74 treasures, including 12 spell-backed criteria).
The [remaining coordinate list](sources/criterion-waypoint-gaps.csv) is a
research queue, not guessed locations. The other 38 candidate decorations from
this initial audit were subsequently source-verified and added in release
1.15.0; see the [follow-up audit](audit-followup-2026-09-07.md).
